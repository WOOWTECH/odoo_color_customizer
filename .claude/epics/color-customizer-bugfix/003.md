## Technical Details

### Deployment Steps

```bash
# 1. Copy module to server
scp -r odoo_color_customizer/ ha-192-168-2-254:/addon_configs/local_odoo/odoo_custom_addons/
```

3. Find Color Customization section
4. Click "Reset to Default"
5. Screenshot the navbar
