# Task: Update SCSS fallback color values

## Description

Update the CSS custom property fallback values in `color_overrides.scss` to use the correct Odoo Community default color (`#71639e`) instead of the Enterprise color (`#714B67`). This ensures the fallback values match when the theme CSS hasn't loaded yet.

## Acceptance Criteria

- [ ] `--custom-primary` fallback updated to reference correct default
- [ ] `--custom-primary-hover` recalculated (10% darker than `#71639e`)
- [ ] `--custom-primary-active` recalculated (20% darker than `#71639e`)
- [ ] `--custom-primary-light` recalculated (85% lighter than `#71639e`)
- [ ] Comment added explaining these are Odoo 18 Community defaults

## Technical Details

### File to Modify

**`odoo_color_customizer/static/src/scss/color_overrides.scss`** (lines 9-16)

```scss
// Before
:root {
  // Fallback values if custom properties not loaded
  --custom-primary: var(--o-brand-odoo, #714B67);
  --custom-primary-hover: #5a3c52;
  --custom-primary-active: #4a3244;
  --custom-primary-light: #f0e8ed;
  --custom-primary-text: #ffffff;
}

// After
:root {
  // Fallback values - Odoo 18 Community defaults (from $o-community-color: #71639e)
  --custom-primary: var(--o-brand-odoo, #71639e);
  --custom-primary-hover: #66598f;    // 10% darker
  --custom-primary-active: #5b4f80;   // 20% darker
  --custom-primary-light: #eeedf2;    // 85% lighter
  --custom-primary-text: #ffffff;
}
```

### Color Calculations

Base color: `#71639e` (RGB: 113, 99, 158)

| Variant | Calculation | Result |
|---------|-------------|--------|
| hover | 10% darker | `#66598f` |
| active | 20% darker | `#5b4f80` |
| light | 85% lighter | `#eeedf2` |
| text | Contrast check | `#ffffff` (white - base is dark enough) |
