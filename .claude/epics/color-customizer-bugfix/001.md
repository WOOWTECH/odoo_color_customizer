# Task: Fix default color constants in Python files

## Description

Update the hardcoded default color constant from `#714B67` (Odoo Enterprise) to `#71639e` (Odoo Community) in all Python files. This is the root cause of Bug #2 where reset produces a different appearance than a clean Odoo installation.

## Acceptance Criteria

- [ ] `controllers/main.py` line 10: `DEFAULT_PRIMARY_COLOR = '#71639e'`
- [ ] `models/res_config_settings.py` line 9: `DEFAULT_PRIMARY_COLOR = '#71639e'`
- [ ] Comment updated to reference "Community" color, not just "Odoo purple"
- [ ] No other hardcoded `#714B67` values remain in Python files

## Technical Details

### Files to Modify

1. **`odoo_color_customizer/controllers/main.py`**
   ```python
   # Before (line 10)

   # After
   ```
