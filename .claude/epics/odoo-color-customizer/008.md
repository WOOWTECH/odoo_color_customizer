# Odoo Color Customizer

Customize the primary brand color in Odoo 18 without modifying core code.

## Features

- 🎨 **Color Picker** - Visual color selection in General Settings
- ⚡ **Live Preview** - See changes instantly without page reload
- 💾 **Persistent** - Color setting persists across sessions
- 🔄 **Reset Option** - One-click reset to default Odoo purple

## Installation

### Via Docker (Home Assistant)

```bash
# Copy module to container
scp -r odoo_color_customizer ha-192-168-2-254:/tmp/
ssh ha-192-168-2-254 "docker cp /tmp/odoo_color_customizer addon_local_odoo:/opt/odoo/addons/"

# Install module
ssh ha-192-168-2-254 "docker exec addon_local_odoo bash -lc 'odoo -c /addon_config/odoo/conf/odoo.conf -d odoo -i odoo_color_customizer --stop-after-init'"
```

### Manual Installation

1. Copy `odoo_color_customizer` folder to your Odoo addons path
2. Restart Odoo server
3. Go to Apps > Update Apps List
4. Search "Color Customizer" and install

## Usage

1. Navigate to **Settings > General Settings**
2. Scroll to **Color Customization** section
3. Click the color picker to select a new primary color
4. The color applies immediately - no save required for preview
5. Click **Save** to persist the color
6. Use **Reset to Default** to restore Odoo purple (#714B67)

## Configuration

The primary color is stored in `ir.config_parameter`:
- Key: `odoo_color_customizer.primary_color`
- Default: `#714B67`

## Troubleshooting

### Color not applying
1. Clear browser cache
2. Hard refresh (Ctrl+Shift+R)
3. Check browser console for errors

### Color reverts after restart
1. Ensure you clicked Save in settings
2. Check ir.config_parameter for the stored value

### Live preview not working
1. Ensure JavaScript is not blocked
2. Check console for errors
