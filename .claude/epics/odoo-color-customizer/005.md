# Task: CSS Overrides

## Description
Create SCSS file that defines CSS variable overrides for all Odoo UI elements using the primary color. This ensures comprehensive color coverage across buttons, links, forms, and other components.

## Acceptance Criteria
- [ ] SCSS file created with all necessary overrides
- [ ] Primary buttons use custom color
- [ ] Links use custom color
- [ ] Form focus states use custom color
- [ ] Selection highlights use custom color
- [ ] Navbar accents use custom color
- [ ] Kanban card accents styled
- [ ] No visual regressions

## Technical Details

### File: `static/src/scss/color_overrides.scss`
```scss
// Color Customizer - CSS Variable Overrides
// Uses CSS custom properties set by the controller

:root {
  // Fallback to Odoo default if custom properties not set
  --custom-primary: var(--o-brand-odoo, #714B67);
  --custom-primary-hover: var(--custom-primary-hover, #5a3c52);
  --custom-primary-active: var(--custom-primary-active, #4a3244);
  --custom-primary-light: var(--custom-primary-light, #f0e8ed);
  --custom-primary-text: var(--custom-primary-text, #ffffff);
}

// Override Odoo's brand colors
.o_main_navbar {
  background-color: var(--custom-primary) !important;
}

// Primary buttons
.btn-primary {
  background-color: var(--custom-primary) !important;
  border-color: var(--custom-primary) !important;
  color: var(--custom-primary-text) !important;

  &:hover, &:focus {
    background-color: var(--custom-primary-hover) !important;
    border-color: var(--custom-primary-hover) !important;
  }

  &:active, &.active {
    background-color: var(--custom-primary-active) !important;
    border-color: var(--custom-primary-active) !important;
  }
}

// Outline buttons
.btn-outline-primary {
  color: var(--custom-primary) !important;
  border-color: var(--custom-primary) !important;

  &:hover, &:focus {
    background-color: var(--custom-primary) !important;
    color: var(--custom-primary-text) !important;
  }
}

// Links
a {
  color: var(--custom-primary);

  &:hover {
    color: var(--custom-primary-hover);
  }
}

// Form elements
.form-control:focus,
.form-select:focus {
  border-color: var(--custom-primary) !important;
  box-shadow: 0 0 0 0.2rem var(--custom-primary-light) !important;
}

// Checkboxes and radios
.form-check-input:checked {
  background-color: var(--custom-primary) !important;
  border-color: var(--custom-primary) !important;
}

// Selection highlights
.o_list_view .o_data_row.o_selected_row {
  background-color: var(--custom-primary-light) !important;
}

// Kanban cards
.o_kanban_record .o_kanban_card_header {
  border-left-color: var(--custom-primary) !important;
}

// Progress bars
.progress-bar {
  background-color: var(--custom-primary) !important;
}

// Badges
.badge-primary,
.badge.bg-primary {
  background-color: var(--custom-primary) !important;
}

// Calendar events
.fc-event {
  background-color: var(--custom-primary) !important;
  border-color: var(--custom-primary) !important;
}

// Dropdown active items
.dropdown-item.active,
.dropdown-item:active {
  background-color: var(--custom-primary) !important;
}

// Pagination
.page-item.active .page-link {
  background-color: var(--custom-primary) !important;
  border-color: var(--custom-primary) !important;
}

// Tabs
.nav-tabs .nav-link.active {
  border-bottom-color: var(--custom-primary) !important;
}

.nav-pills .nav-link.active {
  background-color: var(--custom-primary) !important;
}

// Text utilities
.text-primary {
  color: var(--custom-primary) !important;
}

.bg-primary {
  background-color: var(--custom-primary) !important;
}

// Odoo specific components
.o_statusbar_status button.btn-primary {
  background-color: var(--custom-primary) !important;
}

.o_searchview_facet {
  background-color: var(--custom-primary-light) !important;
}
```
