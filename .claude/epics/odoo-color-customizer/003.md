# Task: Settings View

## Description
Create the XML view to add a color picker field to Settings > General Settings. Uses Odoo's built-in color widget for the color selection interface.

## Acceptance Criteria
- [ ] Color picker appears in General Settings
- [ ] Field uses `widget="color"` for native color picker
- [ ] "Reset to Default" button visible
- [ ] Current color hex value displayed
- [ ] Section labeled "Color Customization"
- [ ] Help text explains the feature

## Technical Details

### File: `views/res_config_settings_views.xml`
```xml
<?xml version="1.0" encoding="utf-8"?>
<odoo>
    <record id="res_config_settings_view_form_color" model="ir.ui.view">
        <field name="name">res.config.settings.view.form.inherit.color.customizer</field>
        <field name="model">res.config.settings</field>
        <field name="inherit_id" ref="base_setup.res_config_settings_view_form"/>
        <field name="arch" type="xml">
            <xpath expr="//app[@name='general_settings']" position="inside">
                <block title="Color Customization" name="color_customization">
                    <setting string="Primary Color" help="Customize the primary brand color used throughout Odoo">
                        <div class="content-group">
                            <div class="row mt16">
                                <label for="primary_color" class="col-lg-3 o_light_label"/>
                                <field name="primary_color" widget="color" class="col-lg-9"/>
                            </div>
                            <div class="row mt8">
                                <div class="col-lg-3"/>
                                <div class="col-lg-9">
                                    <span class="text-muted">Current: </span>
                                    <field name="primary_color" readonly="1" class="d-inline"/>
                                </div>
                            </div>
                            <div class="row mt8">
                                <div class="col-lg-3"/>
                                <div class="col-lg-9">
                                    <button name="action_reset_primary_color"
                                            type="object"
                                            string="Reset to Default"
                                            class="btn-link"
                                            confirm="Reset primary color to Odoo default (#714B67)?"/>
                                </div>
                            </div>
                        </div>
                    </setting>
                </block>
            </xpath>
        </field>
    </record>
</odoo>
```
