# Fix Plan: Remaining Purple Color Bugs

## Date: 2026-01-08

## Bugs to Fix

### Bug 1: Input Hover Border Shows Purple
- **Location:** https://matt-test-254-odoo.woowtech.io/odoo/products/new
- **Element:** Any input text field on hover
- **Root Cause:** CSS variable `--o-input-border-color` is set to `#71639e` in:
  ```css
  .o_required_modifier { --o-input-border-color: #71639e; }
  .o_field_widget:focus-within { --o-input-border-color: #71639e; }
  ```
- **Why Current Fix Doesn't Work:** BUG FIX 7 only covers `.form-check:hover` and `.form-select:hover` but NOT the CSS variable that controls input borders.

### Bug 2: Calendar Day Hover/Click Shows Purple
- **Location:** https://matt-test-254-odoo.woowtech.io/odoo/calendar (right-side mini calendar)
- **Element:** Non-today days when hovered or clicked
- **Root Cause:** Multiple CSS rules:
  ```css
  .o_datetime_picker .o_selected:not(.o_select_start):not(.o_select_end) {
      background: rgb(221, 219, 232); /* light purple */
  }
  .o_datetime_picker .o_current::before {
      box-shadow: rgb(113, 99, 158) 0px 0px 0px 1px inset; /* purple border */
  }
  ```
- **Why Current Fix Doesn't Work:** BUG FIX 9 targets `.o_date_item_picker .o_datetime_button` but the mini calendar uses different selectors.

## Fix Plan

### Fix 1: Override CSS Variable for Input Borders
Add after BUG FIX 12 (line 254):
```css
/* ============================================================================
   BUG FIX 13: Override --o-input-border-color CSS variable
   This variable controls input border color for required/focused fields
   ============================================================================ */
.o_required_modifier {
    --o-input-border-color: {primary_color} !important;
    --o-caret-color: {primary_color} !important;
}

.o_field_widget:focus-within {
    --o-input-border-color: {primary_color} !important;
    --o-caret-color: {primary_color} !important;
}

/* Also override the hover state for all inputs */
.o_field_widget:hover {
    --o-input-border-color: {primary_color} !important;
}
```

### Fix 2: Override Calendar Day Selected and Current States
Add after BUG FIX 13:
```css
/* ============================================================================
   BUG FIX 14: Calendar mini picker selected/current day colors
   Override the light purple background and purple border
   ============================================================================ */
.o_datetime_picker .o_selected:not(.o_select_start):not(.o_select_end) {
    background: {light_color} !important;
}

.o_datetime_picker .o_current::before,
.o_datetime_picker .o_highlighted::before,
.o_datetime_picker .o_select_start::before,
.o_datetime_picker .o_select_end::before {
    box-shadow: {primary_color} 0px 0px 0px 1px inset !important;
}

.o_datetime_picker .o_select_start::before,
.o_datetime_picker .o_select_end::before {
    background: {light_color} !important;
}

.o_datetime_picker .o_select_start:not(.o_select_end)::after,
.o_datetime_picker .o_select_end:not(.o_select_end)::after,
.o_datetime_picker .o_select_start:not(.o_select_start)::after,
.o_datetime_picker .o_select_end:not(.o_select_start)::after {
    background: {light_color} !important;
}
```
